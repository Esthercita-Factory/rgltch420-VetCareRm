# rgltch420-VetCareRm
VetCare RM es un sistema de gestión para clínicas veterinarias desarrollado en C# 14 utilizando .NET, una arquitectura en capas y ejecutado inicialmente como una aplicación de consola. Su objetivo es facilitar la administración de pacientes veterinarios, propietarios, citas médicas e historial clínico mediante una estructura escalable y mantenible.

En su primera versión, el sistema permitirá registrar, consultar y administrar pacientes y sus mascotas, implementando validaciones, manejo de errores y una clara separación de responsabilidades entre las distintas capas de la aplicación.

Como parte de la ruta avanzada, el proyecto se desarrollará utilizando Docker para estandarizar el entorno de ejecución y almacenamiento local de datos durante las primeras iteraciones, permitiendo una futura migración a bases de datos relacionales como PostgreSQL sin modificar la lógica de negocio.
